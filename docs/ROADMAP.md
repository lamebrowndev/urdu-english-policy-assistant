# Roadmap

| Phase | Scope | Exit criteria |
|---|---|---|
| 1. Ingestion foundation | Schema, Urdu normalization, extraction quality gate, chunking, idempotent ingest, CLI, CI | This ticket's acceptance criteria |
| 2. Hybrid retrieval — done | bge-m3 vectors in pgvector (HNSW + iterative scans); Okapi BM25 in SQL over an Urdu-folded inverted index; ACL filter inside both queries; reciprocal rank fusion; bge-reranker-v2-m3; retrieval eval CLI (Recall@k, MRR) with ablations | BM25 scores match a reference implementation to 1e-6; property test: no result outside the caller's ACL; Recall@10 measured on a seed set |
| 3. Cited answers + audit log — done | Claude API (model configurable) with Citations over one custom-content document per chunk (sentences as blocks); answer in the question's language; two-layer abstention; refusal handling; append-only audit log storing the exact context sent | Every citation maps to a provided sentence; "restricted" and "not found" abstentions are indistinguishable; UPDATE/DELETE on audit rows rejected by the database |
| 4. Access control + UI | Authenticated HTTP API, users, groups, sessions; chat UI with RTL layout, Nastaliq font and citation panel; reviewer queue over the audit log. The HTTP API moved here so no endpoint ever trusts client-supplied groups. | HTTP API never trusts client-supplied groups; role tests pass; human browser checks |
| 5. Evaluation | Dev set (~100) + frozen test set (200: 100 Urdu / 100 English; slices: lookup, synthesis, cross-lingual, unanswerable, permission); gold evidence as (document, page, quote); written rubric; human scoring in the reviewer UI; LLM judge for dev iterations only, calibrated against human labels; bootstrap 95% CIs; slice and ablation tables | Test-set hash recorded before the final run; results JSON committed; README numbers reproducible from it |
| 6. Showcase | README with architecture diagram, results with CIs, limitations, threat model; demo GIF; one-command demo | Human final review |
