# Roadmap

| Phase | Scope | Exit criteria |
|---|---|---|
| 1. Ingestion foundation — done | Schema, Urdu normalization, extraction quality gate, chunking, idempotent ingest, CLI, CI | Ingest tests pass; quarantined documents never reach the index |
| 2. Hybrid retrieval — done | bge-m3 vectors in pgvector (HNSW + iterative scans); Okapi BM25 in SQL over an Urdu-folded inverted index; ACL filter inside both queries; reciprocal rank fusion; bge-reranker-v2-m3; retrieval eval CLI (Recall@k, MRR) with ablations | BM25 scores match a reference implementation to 1e-6; property test: no result outside the caller's ACL |
| 3. Cited answers + audit log — done | Claude API with Citations over one custom-content document per chunk (sentences as blocks); answer in the question's language; two-layer abstention; refusal handling; append-only audit log storing the exact context sent | Every citation maps to a provided sentence; "restricted" and "not found" abstentions are indistinguishable; UPDATE/DELETE/TRUNCATE on audit rows rejected by the database |
| 4A. Access control + HTTP API — done | Authenticated HTTP API, users, groups, server-side sessions, reviewer queue over the audit log. No endpoint trusts client-supplied groups. | Role, session, CSRF, and review tests pass |
| 4B. Web UI — done | Server-rendered chat with per-block RTL/Nastaliq, citation links, language toggle, reviewer queue and item pages | HTML/CSP/XSS tests pass; checked in Chrome: forms, citations, Urdu direction, 360 px width, keyboard |
| 5. Evaluation — harness done, results pending | Answer datasets (sample, dev, frozen test) with answerable/unanswerable/restricted categories and question-type tags; evidence and category checks against the index and ACLs; runs through the production answer path; human scoring in the reviewer UI with the evaluation reference; Wilson 95% intervals by language, category, and tag. See [EVALUATION.md](EVALUATION.md). | Real corpus ingested; 200-question test set frozen; complete human-scored run; results JSON committed; README numbers reproducible from it |
| 6. Showcase — in progress | README with architecture, security model, and limitations; `make demo`; threat model in [SECURITY.md](SECURITY.md); screenshots after the first real answers | Human final review |
